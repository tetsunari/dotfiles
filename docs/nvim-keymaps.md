# Neovim・VS Code キーマップ一覧

現在の設定で明示しているキーの一覧です。Vim・VS Code・各プラグインの標準操作全体を網羅するものではありません。

- **leader**：Mac・WSL2ともに `Space`
- **localleader**：既定の `\`（leaderとは別）
- `Space f`：Space、fの順に押す
- `Ctrl+f`：Controlとfを同時に押す
- `⌘`：MacのCommandキー
- モード：**N**＝ノーマル、**I**＝挿入、**V**＝選択、**O**＝操作待ち（`d`・`c`などの後）
- VS Codeでは **VS Code Neovim** を使用し、競合する **VSCodeVimは無効化**する

## Neovim共通の編集操作

| キー | モード | 操作 |
|---|---|---|
| `jj` | I | ノーマルモードへ戻る |
| `x` | N | カーソル位置の文字を削除。レジスタを上書きしない |
| `X` | N | 直前の文字を削除。レジスタを上書きしない |
| `s` | N | 文字を削除して挿入モードへ。レジスタを上書きしない |
| `p` / `P` | N・V | 改行コードを正規化して貼り付け |
| `Ctrl+s` | N | 保存 |
| `so` | N・V | スクリプトを読み込む（`:source`） |
| `Ctrl+a` | I（VS Code／WSL2） | 行の最初の非空白文字へ移動して挿入 |
| `Ctrl+d` | I | 挿入モードを抜け、カーソル位置の文字を置換 |
| `Ctrl+v` | I・Linux/WSL2 | システムクリップボードから貼り付け |
| `ZZ` / `ZQ` | N | 無効化 |

Macの `⌘V` は端末・VS Code側の貼り付けを使用します。通常ファイルでは、以下のundo-glow設定がNモードの `p` / `P` を上書きします。

## WezTerm内のNeovim：Macの保存・Emacs風カーソル移動

| キー | モード | 操作 |
|---|---|---|
| `⌘S` | N・I・V | 保存。WezTermがNeovimへCommand+Sを送信 |
| `Ctrl+a` | I | 行頭へ移動 |
| `Ctrl+e` | I | 行末へ移動 |
| `Ctrl+b` | I | 左へ1文字移動 |
| `Ctrl+f` | I | 右へ1文字移動 |
| `Ctrl+p` | I | 上へ1行移動。補完候補表示中は前の候補 |
| `Ctrl+n` | I | 下へ1行移動。補完候補表示中は次の候補 |

カーソル移動は挿入モードを維持します。VS Code側のカーソル移動設定は変更しません。
WezTermの `⌘S` は、前面プロセス名による判定を挟まず保存キーを直接送信します。
Neovimの `<D-s>` に割り当てているため、Oilの `Ctrl+s`（分割）とも区別できます。

## VS CodeのLazyGit拡張

拡張は内部でエディタ領域のターミナルを作成します。`terminalFocus && lazygitFocus` の条件で、以下の送信設定を優先します。

| キー | LazyGitへ送るキー | 操作 |
|---|---|---|
| `Ctrl+j` | `Alt+↓` | コミットを下へ移動 |
| `Ctrl+k` | `Alt+↑` | コミットを上へ移動 |

LazyGit標準の代替キーを使い、Ctrl+Jの改行コードとの衝突を避けます。

## 設定上の注意点

| キー | 注意点 |
|---|---|
| `Space f` / `Space ff` | VS Codeは `Space f`、単体Neovimは `Space ff` |
| `Space u` | Git変更の取り消し。通常のUndoは `u` |
| `Space q` | VS Codeでは「現在以外のエディタを閉じる」 |
| `Ctrl+s` | 通常は保存。Oil内では分割して開く |
| 挿入モードの `Ctrl+s` | 追加の保存割り当ては削除し、Neovim標準の関数の引数情報表示を使用 |
| WezTerm内の `⌘S` | Neovimの保存キーとして送信。VS Codeターミナル向けの追加割り当ては撤去 |
| `Ctrl+l` | VS Code側の領域移動と、Oil側の更新が重複 |
| `,` | レジスタ置換と、CamelCaseMotionの接頭キーが重複 |
| `Space s` / `Space sm` | FlashとMarkdown表示切り替えが接頭キーを共有 |
| Markdown Toggle | 現設定では専用キーを割り当てていない |
| Obsidian連携 | 設定全体をコメントアウトして無効化。通常のMarkdown編集では読み込まない |
| nvim-scrollbar | 既存の設定と検索ハンドラに対応する `v1` ブランチへ固定 |

# 検証ループ

## 完了の定義

「実装した」≠「完了」。以下を全て満たして初めて完了とする：

1. **動作証明** — 変更が期待通り動くことを実際に確認した
2. **既存破壊なし** — 既存の動作を壊していないことを確認した
3. **エラーなし** — ビルド・型チェック・lint がクリーンな状態

## 確認手順（タスク種別ごと）

| タスク種別 | 最低限の確認 |
|-----------|------------|
| コード変更 | テスト実行 → ビルド確認 → 型エラーなし |
| バグ修正 | 修正前の再現 → 修正後の解消を確認 |
| 設定変更 | 変更後の動作ログを目視確認 |
| リファクタリング | テスト全パス → 動作変化なし |

## 禁止事項

- テスト未実行のまま「完了しました」と報告しない
- エラーを握りつぶして「動きます」と言わない
- 「おそらく動くはず」での完了宣言禁止

## 検証できない場合の対応

確認環境がない・テストが存在しない場合は：
1. その旨をユーザーに明示する
2. 手動確認すべき項目をリストアップして渡す
3. 「未検証」と明記して完了としない

# AI文体の見落とし候補（検出補助）

手順3の照合で、Claudeが見落としやすい箇所を拾うためだけに使う。ここに載る語の有無で合否を決めない。Geminiへの依頼文・修復指示にこの表を転記しない。修復時に伝えるのは、実際に読みにくさや意味の曖昧さを確認した箇所だけとする。

出典：[nanaism/yomiyasu](https://github.com/nanaism/yomiyasu)（MIT、`../scripts/LICENSE-yomiyasu`）の slop-catalog から抜粋した。技術文書で通常の語として使われる語群（実測・照合・既定・定番など）を含む「急増語」節と、書式規範と衝突する記号ルール（文末コロン・補足カッコ・和欧文間空白）は除いた。

## lint の使い方

```bash
python3 ~/.claude/skills/japanese-natural-writing/scripts/yomiyasu_lint.py <候補本文のファイル>
```

標準入力も受け付ける。参照するのは語彙・構文系の警告（AI頻出語彙、比喩動詞、前置き・定型文、「AではなくB」、同一文末の連続、絵文字）だけ。太字頻度・箇条書き比率・コロン・カッコ・和欧文空白の警告は呼出し側の書式規範が優先するため無視する。スコアは報告に使わない。

警告箇所は原文と候補を読んで判断する。比喩が指す操作を原文から一意に特定できない場合は、具体化すると創作になるため変更を求めない（[共通原則](02-core-rules.md)の抽象的な比喩の扱いに従う）。

## 比喩動詞

| 語 | 典型例 | 原文から特定できる場合の言い換え |
|---|---|---|
| 効く | 地味に効きます | 役に立つ、〜を防げる |
| 壊れる | 静かに壊れる | 例外が出る、整合性が崩れる |
| 倒す | 残さない側に倒す | 〜を原則とする、除外する |
| 溶かす | 時間を溶かした | 時間を費やした |
| 潰す | 1つずつ潰す | 1件ずつ解消する |
| 踏み込む | 〜まで踏み込んで | 内部実装まで調べて |
| 添える | 経路が代わりに添える | 参照する、渡す |
| 収斂する | その価格帯に収斂した | 〜に決まった |
| 沈黙する／黙って | 黙って捨てられる | 通知なく破棄される |

## 英語直訳調

| 原表現 | 直訳調 | 自然な日本語 |
|---|---|---|
| silently fail | 静かに失敗する | エラーを出さずに失敗する |
| the moment ... | 〜した瞬間 | 〜した直後に、〜した時点で |
| single source of truth | 〜を正本にする | 唯一の情報源とする |
| load-bearing | 構造を支える | 不可欠な、外せない |
| it is not X, it is Y | Xではなく、Yです | Yです（Xの否定が論点でない場合） |
| delve into | 深く分け入る | 詳しく調べる |

## 体験の壮大化・疑似具体語

- 壮大化：真理、宿命、境地、極致、深淵、結晶など。個人の体験や日常的な判断に普遍の教訓を付けていないかを見る。
- 質感を装う語：手触り、肌感、温度感、熱量、血の通った、泥臭い。
- 認知を装う語：解像度を上げる、腹落ち。何をどこまで調べたかが原文にあれば、それを書く。
- 評価を装う語：本質的、地に足のついた、等身大。

医学の体温、画像処理の解像度のように、文脈上の専門用語や事実の記述なら変更しない。

## 前置き・定型句

- 前置き：重要なのは、結論から言うと、ここで注目すべきは
- 後置ラベル：〜というわけです、〜に他なりません、面白いのはここです
- 定型の結び：いかがでしたでしょうか、〜の参考になれば幸いです

前置きの削除は内容を変えない場合に限る。著者の評価や意見そのものは削らない（[検証・修復基準](08-review.md)）。

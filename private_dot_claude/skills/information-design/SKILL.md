# Information Design Skill

スライド・レポート・ダッシュボード・提案書の情報設計を体系的にレビュー・改善する。
目標: **「見た人が主要点を素早く理解し、誤解なく意思決定できる状態をつくる」**

## When to Activate

- PowerPoint / スライドの構成検討
- レポートの内容改善（見出し・グラフ・文言）
- ダッシュボードのページ設計
- グラフ種類の選定
- KPI資料のレビュー
- 提案書のビジュアライゼーション改善
- 既存資料の再構成

## Core Design Principles

### 原則1: 1ページ1メッセージ
各ページには「1文で表現できるメッセージ」を1つだけ置く。タイトル・見出しにそのメッセージを反映させる。

### 原則2: 比較しやすさを優先
見た目の美しさより「差・推移・ランキングがすぐ見える構造」を選ぶ。

### 原則3: 情報過多を避ける
重要情報を埋もれさせない。1ページの論点を絞る。補足は周辺に配置する。

### 原則4: 言葉で意味を補完
色・位置だけに頼らない。数値には単位を付ける。グラフには対象・期間・粒度を明記する。

## Graph Selection Guide

| 目的 | 推奨グラフ |
|------|-----------|
| 時系列変化 | 折れ線グラフ（系列は重ねすぎない） |
| 項目比較 | 棒グラフ（ラベルが長い場合は横棒） |
| 構成比 | 積み上げ棒 / 集合棒（円グラフより優先） |
| 差異の強調 | 差分を視覚化・前後比較を明示 |
| 棒グラフのゼロ点 | 原則ゼロ起点（比較が著しく損なわれる場合は注記付きで調整可） |

**円グラフ使用条件**: 項目が2〜3個で直感的な割合強調が目的の場合のみ

## Composition Rules

**スライド / ページ**: 結論→根拠→詳細→補足の順。重要情報は左上または冒頭に配置。

**レポート**: 見出しだけで流れが伝わるように。段落は1メッセージ1段落。長い説明の前に短い要約を置く。

## Title Requirements

必須要素: **主題・期間・粒度・単位・比較基準**

| 悪い例 | 良い例 |
|--------|--------|
| 「売上」 | 「月次売上推移（税抜・2026年1〜3月）」 |
| 「進捗状況」 | 「月次申請件数の推移（前年同月比）」 |
| 「結果」 | 「施策A/B テスト結果（CVR・3月1〜15日）」 |

## Visual Standards

**数値**: 単位必須・千桁区切り・不要な小数点は省略

**色**:
- 強調色は1〜2色に限定
- 赤は未達・警告・異常のみに使用
- ページ間で色の意味を統一
- 色だけで意味を伝えない（記号・ラベル併用）

**レイアウト**: 視線の流れに沿う・余白を確保・要素を整列・役割（タイトル・本文・グラフ・注記）を視覚的に区別

**表**: 行・列の意味を即座に把握できるように。数値は書式統一。強調は選択的に。推移分析はグラフ化を検討。

## Prohibited Practices

- 3Dグラフ
- 円グラフの多用
- 単位なし数値
- 過剰な装飾要素
- 1ページへの詰め込み
- 軸設定・配置の不明確さ
- 読者の背景知識を前提とした説明

## Exception Conditions

- 経営層向け資料: 一覧性より「一瞬で判断できる事実」を優先。タイトルはカテゴリでなく判断を伝える形に。
- ブランド制約: 可読性を損なわない範囲で許容。

## Review Checklist

1. **主メッセージ**: 1文で表現可能か? タイトル・見出しに反映されているか?
2. **情報量**: 過多でないか? 重要データが埋もれていないか? 不要な補足が邪魔していないか?
3. **グラフ選定**: 目的に合っているか? 比較・推移・構成・差異の処理は適切か?
4. **タイトル・注記**: 主題・期間・粒度・単位を含むか? 比較基準が明確か? 誤解の余地がないか?
5. **色・レイアウト**: 強調色が抑制されているか? 意味が一貫しているか? 視線の流れが自然か? 余白・整列が適切か?

## Output Workflow

1. 主メッセージを定義
2. 構造・グラフ種類を選定
3. タイトル・色・レイアウトを整備
4. 禁止事項とチェックリストで監査

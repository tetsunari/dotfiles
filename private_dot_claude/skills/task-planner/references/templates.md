# Task Planner Templates

`task-planner/SKILL.md` から切り出した実装計画テンプレート集。

## Phase 2: コードベース調査コマンド集

```bash
# 関連ファイル検索
rg "keyword" --type ts

# ディレクトリ構造確認
eza --tree --level=3 src/

# 依存関係確認
npm ls <package-name>

# 型定義確認
rg "interface|type" --type ts src/types/
```

## Phase 4: 依存関係図テンプレート

```mermaid
graph TD
    A[Task 1: 型定義] --> B[Task 2: Repository]
    A --> C[Task 3: Service]
    B --> D[Task 4: API Handler]
    C --> D
    D --> E[Task 5: テスト]
    D --> F[Task 6: ドキュメント]
```

### クリティカルパス
A → B → D → E

### 並列実行可能
- Task 2, Task 3（Task 1完了後）
- Task 5, Task 6（Task 4完了後）

# ドキュメント作成ルール

## 目的

作業者が上からなぞるだけで、誰でも同品質の結果を出せるドキュメントを作る。
属人化を排除し、業務を標準化する。

## ノウハウ

### 表現
- 感情的な言葉・曖昧な表現を排除する
- 1文を短くシンプルにする
- 文字・画像の量は可能な限り最小限に抑える

### 構造
- インデントの階層は最大3つまで
- 各手順に項番を振り、進捗を把握しやすくする
- 入力項目が多い場合はテーブル（表）で整理する

### 効率
- コマンド・設定値はコピー＆ペーストで完結できるようにする

### 視覚
- リスクを伴う危険な作業箇所は **赤文字＋太文字** で強調する
- 画像に頼りすぎず、基本はテキストで伝える

### タイミング
- 作成を後回しにせず、実際の作業をしながらリアルタイムで作成する

## チェックリスト

ドキュメント出力前に自問する：

- [ ] 1文が長すぎないか・曖昧語が混じっていないか
- [ ] インデントが3階層を超えていないか
- [ ] 各手順に項番が振られているか
- [ ] コマンド・設定値はそのままコピペで動くか
- [ ] 危険箇所が視覚的に強調されているか
- [ ] 不要な装飾・水増しがないか

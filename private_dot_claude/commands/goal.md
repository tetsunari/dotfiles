# /goal — スキル反復改善コマンド

スキルに対して改善ゴールを指定し、Find→Verify→Synthesize→Edit のループで繰り返し最適化する。`audit-skills +dynamic` のレポート出力をそのまま入力として使える。

## 使用形式

```
/goal <スキル名> "<改善ゴール文>"
/goal <スキル名> --report "<audit レポート本文>"
```

### 例

```
/goal audit-skills "トリガリング精度を上げ、類似スキルとの競合を排除する"
/goal task-planner --report "C2: エラー対処の分岐が未定義。C8: descriptionが短すぎる"
```

---

## 実行ステップ

### Step 1: 対象スキル読み込み

- 対象の SKILL.md を Read（グローバル `~/.claude/skills/<name>/SKILL.md` → カレント `.claude/skills/<name>/SKILL.md` の順で探索）
- ファイルが見つからない場合はエラー出力して終了

### Step 2: ゴール分解

入力した改善ゴール文を以下の3要素に分解する：

| 要素 | 内容 |
|------|------|
| **What** | 何を改善するか（具体的な問題箇所） |
| **Why** | なぜ問題か（影響・リスク） |
| **How** | どう直すか（具体的な修正方針） |

`--report` 指定時はレポート本文から自動分解する。

### Step 3: Find エージェント（問題特定）

ゴール文と SKILL.md を渡し、以下を調査させる：

```
- ゴールに関連する問題箇所をSKILL.md内で特定
- 修正するとどの行・どの記述が変わるか
- 修正による他箇所への影響（矛盾・整合性崩れ）
```

### Step 4: Verify エージェント（修正案検証）

Find の出力を受け取り、修正案が正しいか検証する：

```
- 修正後のSKILL.mdが意図通りに動くか
- 過剰修正・不足修正がないか
- 新たな問題を生んでいないか
```

### Step 5: 修正適用

Verify で承認された修正を Edit ツールで適用する。

- 複数箇所の修正は並列 Edit
- 修正前後の差分を出力

### Step 6: 改善ループ判定

修正後のSKILL.mdを再評価し、以下を判定する：

| 状態 | 次のアクション |
|------|--------------|
| ゴール達成 | 完了レポートを出力して終了 |
| 残課題あり | 残課題リストを提示し、ループ継続を提案 |
| 新問題が発生 | 新問題を優先ゴールとして提示 |

最大3ループで自動停止（無限ループ防止）。

## 完了レポートフォーマット

```
## /goal 完了レポート

スキル: <名前>
ゴール: <入力ゴール文>
ループ回数: N回

### 適用した修正
| # | 観点 | 変更箇所 | 内容 |
|---|------|---------|------|
| 1 | C8  | description | トリガーフレーズ3件追加 |

### 残課題（次回ゴール候補）
- <残った問題があれば列挙>

### 推奨次アクション
- /audit-skills <name> で全観点再チェック
- /goal <name> "<次のゴール>" で継続改善
```
